# checkup-support

Support and privacy pages for Checkup Lite, a Mac App Store app (by MoleCare LTD) that shows where disk space went on your Mac, keeps a free-space target and clears caches safely.

- Support and common questions: https://yauhenbichel.github.io/checkup-support/
- Privacy policy: https://yauhenbichel.github.io/checkup-support/privacy.html

## How do I report a problem?

Open an issue at https://github.com/YauhenBichel/checkup-support/issues. Say what you expected, what happened, and your macOS version.

This repository holds only the two web pages, not the app source. It has no licence file.
